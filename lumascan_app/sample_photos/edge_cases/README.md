# Synthetic edge-detection camera scenes

Generated by `dart run tool/generate_edge_samples.dart` with a fixed random seed.
These are original synthetic test fixtures, not camera photographs or evidence
of real-world accuracy. Each PNG is 480 x 640 with printed lines and mild noise.
`manifest.json` supplies independent known corners in TL, TR, BR, BL order.

Includes white, black, yellow, pink, blue and green sheets, a multicolour form,
and an equal-luminance colour boundary. The last case intentionally has almost
no grayscale contrast and catches loss of camera chroma before detection.

Bundled in the app; Settings > Developer > Add edge test pages imports them.
`test/colour_preview_test.dart` tests Android NV21 and iOS BGRA conversion,
rotation, padding, absent chroma, blank scenes and the actual preview analyzer.
Real camera photographs remain in `sample_photos/book/` (20 B&W book pages),
`sample_photos/` (5 handwritten pages) and `sample_scan_img/odds_book/` (6 colour
book pages). Keep synthetic and real-photo results separate.
